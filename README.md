# Loadout

Private, offline event inventory and deterministic forecasting for small teams.

## Development

Install FVM, then run `fvm use` and `fvm flutter test`. The pinned SDK is Flutter
3.44.7. This bootstrap contains the cross-platform shell, privacy-first onboarding,
exact fixed-point quantities, and the first direct-consumable forecasting tier.
See [PRODUCT_PLAN.md](PRODUCT_PLAN.md) for delivery gates.
